# 🎓 Teachers’ Day Message Card — Sir Randy Bello

An interactive digital greeting card built with HTML, CSS, and JavaScript to celebrate and honor Sir Randy Bello, our Web Development instructor. This project combines a heartfelt letter, elegant masculine design, smooth animations, and interactive effects to express gratitude in a modern way.

## 📖 Features

🎨 **Elegant Layout** – A stylish masculine design using navy blue, gold, and cream.

💌 **Interactive Letter** – Open and close the greeting letter with a smooth 3D animation.

🌓 **Dark and Light Mode** – Switch between dark and light themes.

✨ **Interactive Animations** – Floating golden particles, glowing effects, smooth transitions, and sparkle animations.

💬 **Personalized Message** – A heartfelt Teachers’ Day letter dedicated to Sir Randy Bello.

📱 **Responsive Design** – Works on desktop and mobile devices.

🖼️ **Embedded Photo** – Includes the instructor’s photo directly in the HTML file.

## 🛠️ Technologies Used

- **HTML5** – Structure and content.
- **CSS3** – Styling, responsive layout, transitions, and animations.
- **JavaScript (ES6)** – Interactive features, theme switching, and dynamic effects.

## 🚀 How to Use

**Open the live website:**

👉 https://ellerex14.github.io/automatic-telegram/

1. Visit the website using your browser.
2. Click **Open the Letter** to reveal the message.
3. Switch between dark mode and light mode.
4. Click the thank-you button to see the celebration animation.

## 🎯 Customization

- **HTML** – Edit the message, title, instructor’s name, and signature.
- **CSS** – Change the colors, fonts, layout, and animations.
- **JavaScript** – Customize the letter-opening effect, theme switcher, and interactive animations.

The project combines HTML, CSS, and JavaScript into a single HTML file for easy editing.

## 💡 Use Cases

- Students sending digital Teachers’ Day greetings.
- Creating a personalized appreciation letter for an instructor.
- Demonstrating web development skills.
- Practicing HTML, CSS, and JavaScript through an interactive project.
